# Glow Studio ✨

A real, dependency-free browser photo editor inspired by the warm, dreamy glow in the reference image.

## Run it

### Easiest
Open `index.html` in Chrome/Edge/Safari.

### Local server (recommended)
From this folder:

```bash
python -m http.server 8000
```

Then open:
http://localhost:8000

## Features
- Drag & drop / mobile photo picker
- Soft glow and bloom
- Warm golden color cast
- Brightness + contrast
- Softness control
- Sparkle overlay
- Vignette
- Soft Glow / Golden Glam / Dreamy presets
- Before/after press-and-hold
- Export as PNG
- Processing happens locally in the browser
